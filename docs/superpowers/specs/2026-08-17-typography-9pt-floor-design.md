# 프로필 SVG 타이포 — 화면상 최소 폰트 플로어 스펙

> **v1.1 개정 (2026-08-17, 같은 날)**: 9pt 플로어 배포 직후 사용자 피드백("폰트가 너무 큰 것 같은데, 한두 포인트만 낮추면")으로 **플로어를 8pt로 하향**. 전 폰트 ×8/9 균일 축소 (선언 최소 18px→16px, 800px 렌더 시 10.67px=8pt), 버튼은 151/176/184×35 (실효 ~10.7px=8.0pt). 레이아웃·캔버스는 9pt 기준 그대로 유지 (여백만 소폭 증가). 아래 본문의 "9pt/18px" 수치는 v1 기준이며 매핑 방법론은 동일하다.

- 날짜: 2026-08-17
- 선행 스펙: `2026-07-17-nerv-profile-eva-v2-design.md` (팔레트·어휘 전부 유지), `2026-08-17-open-source-section-design.md`
- 사용자 지시: "svg 안에 보이는 폰트의 최소 사이즈를 9pt로 올려라" → **화면상 실제 9pt** 기준으로 확정 (선언값 9px 상향은 ×0.69 축소 렌더링 때문에 시각적 효과 없음이 확인됨)

## 1. 기준과 근거

- 9pt = **12 CSS px** (1pt = 96/72 px, 정확값)
- `width="100%"` 자산(1200px 캔버스)은 프로필 README 카드 폭으로 축소 렌더된다. 카드 폭은 창 크기에 따라 변하므로 **보장 하한선 800px**로 설계한다:
  - **선언 최소 18px** → 800px 렌더 시 18 × 800/1200 = **12px = 9pt 보장**
  - 카드가 800px보다 좁은 창에서는 9pt 미만이 될 수 있음 (명시적 한계)
- 버튼(btn-*.svg)은 README에 width 속성이 없어 **고유 크기 1:1 렌더** → 규칙이 다름: **선언 최소 12px**

1. XML 웰폼드 + dark/light `cmp` 동일 (기존 관례)

4. 푸시 후 CI + 실화면 확인 (raw 캐시 ~5분 지연 유의)
